# 文件批量添加序号工具

一个基于 Python 和 Tkinter 的 Windows 桌面应用，用于在预览确认后批量或单个重命名文件，并可从 Word/PDF 内容中提取标题生成文件名。

> 重要：重命名会直接修改原文件名。请先在副本或测试目录中确认预览结果，并备份重要文件。

## 功能

- 三种模式：批量重命名、单个文件重命名、按文档标题重命名。
- 支持序号、日期、时间戳、原文件名组合等预设规则，也可添加前缀、后缀或修改扩展名。
- 批量模式显示原文件与新文件的对应预览；可拖动原文件列表调整处理及编号顺序，按 `F5` 或“刷新文件夹”重新读取目录。
- 可跳过隐藏文件；在“序号_原文件名_日期”规则下可保留已符合该规则的文件，并从现有最大序号继续编号。
- 批量执行时会按当前排序检测文件占用，跳过正在使用的文件并继续处理其余文件。
- 标题模式优先从 Word/PDF 元数据读取标题，失败时再从文档正文推断标题。
- 可对 `序号_原文件名_日期` 格式执行“取消格式”，还原中间的原文件名部分。

## 运行环境

- Windows 10/11（隐藏文件属性检测使用 Windows API；其他平台只能识别点开头的隐藏文件）。
- Python 3.8+；当前项目虚拟环境记录为 Python 3.13。
- 依赖：`python-docx`、`PyPDF2`；Windows 隐藏属性检测建议安装 `pywin32`。

## 从源码运行

在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install python-docx PyPDF2 pywin32
python .\main.py
```

若 PowerShell 阻止激活脚本，可直接使用虚拟环境解释器：

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## 使用方法

1. 选择模式并选择目标文件夹或文件。
2. 选择预设规则；按需设置起始序号、位数、日期格式、前后缀及目标扩展名。
3. 在批量模式中检查右侧预览；需要调整顺序时拖动左侧文件列表。
4. 单击“执行重命名”。标题模式需先单击“提取标题”，除非已勾选“自动重命名”。
5. 仅当文件名满足 `序号_原文件名_日期` 时，才可用“取消格式”移除该格式。

批量执行的占用文件策略：程序将按当前排序逐项检查文件是否被其他程序使用。已占用的文件会被跳过，后续文件仍按当前排序处理；完成后会分别列出成功、跳过和失败的文件。严格按预览中的目标名称执行：跳过带序号的文件时，其原定序号保留为空号，后续文件不重新编号。

### 命名规则

| 预设 | 示例（原文件为 `报告.docx`） |
| --- | --- |
| 序号模式 | `01.docx` |
| 日期模式 | `20260821.docx` |
| 时间戳模式 | `20260821_143012.docx` |
| 序号+原文件名 | `01_报告.docx` |
| 日期+原文件名 | `20260821_报告.docx` |
| 原文件名+序号 | `报告_01.docx` |
| 序号_原文件名_日期 | `01_报告_20260821.docx` |

日期和时间以执行预览时的本机时间生成。若修改序号、日期、后缀或忽略选项，批量预览会刷新。

## 打包 EXE

项目中已有 PyInstaller spec 文件。安装依赖后可执行：

```powershell
pyinstaller --noconfirm ".\文件批量添加序号工具.spec"
```

生成物位于 `dist\`。`build\`、`dist\` 与 `.venv\` 为本机构建/依赖目录，不是业务源码，通常不应提交到版本库。

## 已知限制

- 执行前会阻止重复目标名或覆盖既有文件；执行阶段若遇到权限等运行时错误，已成功的改名不会自动回滚。批量模式会跳过占用文件并继续执行；单文件与标题模式仍会询问是否继续。
- “检查已打开的文件”通过尝试追加打开文件实现，只能作为提示，不能覆盖所有占用情形。
- 标题提取依赖可读取的文本与元数据。扫描版 PDF 或加密文件可能无法成功提取；支持 `.docx` 与含文本的 PDF。
- “取消格式”仅识别 `序号_原文件名_日期`，且原文件名中含下划线时依赖分段拼接来还原。
